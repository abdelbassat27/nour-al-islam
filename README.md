# نور الإسلام — موقع إسلامي شامل

موقع ويب كامل ومجاني يجمع أهم الأدوات الإسلامية اليومية بتصميم راقٍ وعصري.

## المميزات

### 📖 القرآن الكريم
- عرض جميع السور مع النص العثماني
- عدة قراءات/طبعات للنص
- تلاوات صوتية من أشهر القراء (العفاسي، عبد الباسط، الحصري، المنشاوي...)
- ترجمات متعددة
- بحث في النص القرآني
- تشغيل آية بآية أو السورة كاملة

### 🕌 مواقيت الصلاة والأذان
- حساب دقيق حسب المدينة أو الموقع الجغرافي
- عدة طرق حساب (أم القرى، رابطة العالم الإسلامي...)
- عداد تنازلي للصلاة القادمة
- تشغيل أصوات الأذان

### 📿 السبحة الإلكترونية
- عداد ذكي مع أهداف قابلة للتخصيص
- عدة أذكار جاهزة
- إحصائيات يومية محفوظة محلياً
- اهتزاز (على الأجهزة المدعومة)
- حلقة تقدم بصرية

### 🧭 اتجاه القبلة
- بوصلة حية نحو الكعبة
- حساب المسافة
- دعم توجيه الجهاز إن توفر

### 📅 التقويم الهجري
- عرض التاريخ الهجري والميلادي اليوم
- تحويل بين التقويمين

### 🤲 الأدعية وأسماء الله الحسنى
- مجموعة أدعية مأثورة مع مصادرها
- الأسماء الـ 99 مع المعنى

### تصميم ومزايا إضافية
- وضع ليلي / نهاري
- تصميم متجاوب بالكامل (جوال وحاسوب)
- خطوط عربية جميلة للقرآن
- بدون إعلانات وبدون تتبع
- يعمل مباشرة في المتصفح

## طريقة الاستخدام

1. افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Safari, Edge).
2. اسمح بالموقع الجغرافي عند طلبه لمواقيت الصلاة والقبلة.
3. استمتع!

## التقنيات المستخدمة

- HTML5 + CSS3 حديث
- JavaScript خالص (بدون مكتبات)
- APIs مفتوحة:
  - [AlQuran.cloud](https://alquran.cloud) للنص والتلاوات
  - [AlAdhan.com](https://aladhan.com) للمواقيت والتقويم الهجري

## ملاحظات

- التلاوات الصوتية تعتمد على توفرها في CDN الإسلامي.
- بعض المتصفحات تطلب إذناً صريحاً للموقع والصوت.
- الإحصائيات والوضع المظلم تُحفظ في المتصفح محلياً.
